GitHub からリポジトリを clone した後に poetry で環境を作りたい。  
その方法をいつも忘れるのでまとめました。

#### 1. リポジトリに `pyproject.toml` がある場合

```bash
git clone https://github.com/project-name/repo-name.git
cd repo-name

# 仮想環境をプロジェクト内に作成
poetry config virtualenvs.in-project true

# OSごと特定のディレクトリにまとめる
# poetry config virtualenvs.in-project false

# パッケージのインストール
poetry install
```

Q. 今の自分の環境がどこに作られているか確認したい
```bash
poetry config --list
```

#### 2. `requirements.txt` しかないが、Poetry で管理したい場合

```bash
git clone https://github.com/project-name/repo-name.git
cd repo-name

# Poetry を初期化
poetry init --no-interaction
# pyproject.toml が生成される

# requirements.txt の中身を読み込む
# Mac/Linux
poetry add $(cat requirements.txt)
# Windows
# Get-Content requirements.txt | ForEach-Object { poetry add $_ }
```

**※リポジトリ内に環境を作成した場合には、`.gitignore` に `.venv` の追加を忘れないこと。**
